Agentic AI from Scratch

Build a local agent with Ollama and Python, from the loop to guardrails to MCP.

An agent is just a loop. You send a model a prompt plus a list of tools it's allowed to call. It replies with a request like get_weather(city="Austin"), your code runs the function, feeds the result back, and the model continues until it answers in text. That's the entire mechanism. This site teaches it by building one real system, end to end, on your own machine.

Start with Setup Grab a code checkpoint

What you'll build

One Python file that grows page by page into an agent that:

  • Answers questions from a real 58-page PDF handbook, ingested into a persistent vector database with page-level source tracking
  • Refuses to hallucinate: a calibrated retrieval threshold, a citation verifier, and a structural backstop that guarantees every run ends in a real answer
  • Screens incoming prompts through two input guardrails, a free regex pass and a purpose-built guard model, before the main model ever sees them
  • Calls tools from two sources at once: local Python functions and a live MCP server in a separate process, indistinguishable to the model

Two files, no framework. When a vendor says "our platform handles agent orchestration," you'll know exactly what's behind that sentence, because you built it.

Why local-first

Everything here runs through Ollama on your own hardware. No API keys, no credits, no rate limits, no data leaving your laptop.

That matters twice. Agent development is iterative in a way that punishes metered APIs: you'll rerun the same loop dozens of times watching one change shift behavior, and locally a hundred runs cost nothing. And with no hosted framework hiding the loop, you see everything: every message, every tool call, every guardrail firing, in a trace you can read.

When you're ready for a cloud model, the swap is three lines. Going Further shows it.

Who this is for

Solution architects, cloud architects, and technical leads who know APIs, distributed systems, and Python, but haven't built an LLM agent from the wire up. LLM-specific ideas (embeddings, tool calling, context windows) are explained the first time they matter on each page, so you can land anywhere and orient fast.

How to use this site

Reading straight through? Start at Setup and follow the next-page links; the sequence mirrors the book this site is adapted from, and the code accumulates page by page.

Landed here for one thing? Every page stands alone. The most-searched-for pages: calibrating a similarity threshold, why guardrails fail in combination, prompt-injection screening with a guard model, building a minimal MCP server, and troubleshooting by symptom.

Joining mid-sequence? The code checkpoints give you a runnable, known-good file for the end of any construction chapter. Download, rename, run.
